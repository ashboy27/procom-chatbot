The Computer Science Competitions track at PROCOM’26 consists of nine immersive modules, each designed as a self-contained volume within a larger multiverse themed competitive universe. These competitions test problem-solving, logic, creativity, and technical depth across multiple domains of computer science.
Interstellar Intelligence (CS Competition) is a data and logic–driven challenge where participants analyze information and make strategic decisions in unstable environments.
Debug Duel (CS Competition) focuses on identifying and fixing faulty code under time pressure, testing debugging skills and core programming concepts.
Query Quest (CS Competition) is centered on databases and structured queries, where participants retrieve and manage critical data using logical and optimized querying.
Design Dash (CS Competition) is a UI/UX prototyping challenge using Figma, emphasizing creativity, usability, and rapid interface design.
Competitive Programming (CS Competition) is an algorithmic contest testing data structures, problem-solving, optimization, and mathematical reasoning.
Web Forces (CS Competition) evaluates web development and system architecture skills by challenging participants to rebuild and migrate web systems.
Code Sprint (CS Competition) is a speed-based coding challenge focused on rapid logic building and efficient implementation.
Incognito Investigation (CS Competition) is an OSINT-based puzzle competition requiring analytical thinking and digital investigation skills.
Capture The Flag (CS Competition) is a cybersecurity challenge involving cryptography, exploitation, and system security concepts.
