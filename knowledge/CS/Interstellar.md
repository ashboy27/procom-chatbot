Interstellar Intelligence is a Computer Science competition set in Erevos901, held on 11th February from 9:00 AM to 12:00 PM. It is a two-hour real-time programming challenge where teams pilot a ship through a hazardous star system by solving algorithmic and logical puzzles to collect artifacts and escape before collapse. Teams of 1 to 3 members may participate using Python or C++. The competition tests programming fundamentals, graph algorithms (BFS, Dijkstra, A*), mathematics, and 2D coordinate-based physics. VS Code and calculators are allowed. Internet access is limited to Git or GitHub for cloning and submission only, while AI tools, forums, cloud services, and external communication are prohibited. Offline documentation and printed references are permitted. Any misconduct, AI misuse, or reuse of prior code results in disqualification.Personal laptops are not allowed.
