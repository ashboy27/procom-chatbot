Web Forces is a Computer Science competition set in InfraVerse, running from 9:00 AM to 12:00 PM. It is a three-hour full-stack MERN challenge where teams are given a broken repository containing frontend and backend issues, missing pages, redundant components, and non-functional features. Participants must identify and fix these issues within a single onsite, lab-based round. Teams may consist of 1 to 3 members. All fixes must be submitted through one final pull request, and only the last submitted PR will be evaluated. Internet access is permitted strictly for documentation purposes, while the use of AI or LLM-based tools is prohibited. Mobile devices are not allowed during the competition. Any collaboration with other teams, plagiarism, sabotage, or code sharing will result in disqualification. Points are awarded for each verified fix, with ties resolved based on submission time.Personal laptops are not allowed. The Web Forces rulebook is available at: https://drive.google.com/file/d/1QyvOQWsmEmsiimVaUkLKRq6zLXm-jdpl/view
